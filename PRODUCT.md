# Product

## Platform

web

## Stack

Modern static web (Vanilla HTML, CSS, JavaScript) — lightweight, zero build overhead.

## Users

Prospective clients, collaborators, employers, and design/tech peers evaluating Peter Salerno's projects, technical expertise, creative philosophy, and professional background.

## Product Purpose

Serve as the definitive digital portfolio and showcase for Peter Salerno, presenting featured case studies, selected work, creative philosophy, and direct contact channels through a high-craft, high-performance web experience.

## Positioning

A bespoke, art-directed personal showcase that demonstrates technical precision and design maturity through deliberate typography, spatial balance, and seamless responsive execution without relying on bloated frameworks or generic templates.

## Operating Context

Evaluated across modern desktop, tablet, and mobile web browsers. Often reviewed in fast-scanning evaluation contexts (hiring managers, clients) where performance, visual polish, and frictionless access to project proof points directly determine credibility.

## Capabilities and Constraints

- Platform: Static web (Vanilla HTML5, CSS3, ES Modules/JS).
- No heavy build chains or complex framework lock-in required.
- Accessible semantic HTML with clear landmark hierarchy.
- Authentic project case studies and details without generic placeholder content.

## Brand Commitments

- Name: Peter Salerno
- Aesthetic: High craft, refined typography, generous negative space, intentional hierarchy, anti-slop aesthetic.

## Evidence on Hand

- Workspace: `peter-salerno-v2`
- Configured multi-agent environment with global craft and motion skills (`impeccable`, `design-taste-frontend`, `ui-ux-pro-max`, `awwwards`, `jury`, Emil Kowalski motion suite).

## Product Principles

1. **Craft Over Noise:** Every element, typographic choice, and spacing decision is intentional; eliminate ornament that does not serve content or clarity.
2. **Instantaneous Performance:** Pure static implementation ensuring instant page loads, smooth 60fps scrolling, and zero runtime lag.
3. **Rigorous Accessibility:** Accessible contrast (WCAG AA), visible focus states, scalable typography, and touch targets $\ge 44\text{px}$.
4. **Fluid Responsiveness:** Mobile-first considerations ensuring layout integrity and visual elegance across all viewports.

## Accessibility & Inclusion

Targeting full WCAG 2.1 AA compliance: semantic landmarks, accessible color contrast ratios, clear keyboard focus rings, and proper `prefers-reduced-motion` support for all transitions.
